# SHEAF Gate 0 vs Agrimate — Overleaf project

Zip this folder (`main.tex`, `figures/`, `tables/`) and upload to Overleaf
(New Project → Upload Project).

Regenerate figures from the repo root:

```
python scripts/make_agrimate_comparison.py
```

Local copies of Kuhla et al. 2025 live in `agrimate/` at the repo root and are
gitignored (copyright). Cite the published paper; do not upload those PDFs to
Overleaf unless you have rights.
