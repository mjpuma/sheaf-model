\begin{frame}{Jacobi step}
\matchbanner{dynamic\_coupled.\_simulate\_coupled docstring}{dynamic\_coupled.py:112--217}

Each step $t$:

\begin{enumerate}
\item $\mathrm{fac} = \exp(\eta \log(p/p_0))$ for the three world prices
      (all three from the \emph{start} of the step).
\item Each crop runs the Gate~0 market with
      $d^g = C^{\mathrm{flex},g}\cdot\mathrm{fac}_g + C^{\mathrm{ind},g}$.
\item Each crop updates its own $p^g$ exactly as Gate~0.
\end{enumerate}

Networks, AMIS, harvest, warehouses, asks remain per-crop. Coupling is
\textbf{only} through flex demand. Jacobi, not Gauss--Seidel: within a
step, rice does not see the already-updated wheat price.
\bubbles{Jacobi is a numerical protocol, not a parameter.}
{fac dimensionless; $p$ real 2010 \$/t.}
{\texttt{dynamic\_coupled.py:113--114, 121}.}
\end{frame}

\begin{frame}{What Gate 1 does not claim}
\begin{itemize}
\item It does not estimate $\sigma$.
\item It does not turn on the export game.
\item It does not fix Gate~0 consumption leftovers.
\item It does not produce a spatial substitution fingerprint at the
      country level that looks like Agrimate's cross-region plots ---
      there is one world price, so $\Delta C$ from substitution is nearly
      uniform in $p$.
\item 2022 rice drifts the wrong way ($\times 0.99\to\times 1.18$ vs obs
      $\times 0.91$). Disclosed. Not a retune target.
\end{itemize}
