## Agent 1 register — Mathematical foundations (demand system, spatial-equilibrium math)

- **F1 [A, High, 99%].** Claim: the PD guarantee for `M` in `build_demand_system` is false because the per-row diagonal-dominance rescale (`core.py:110-114`) happens BEFORE symmetrization (`core.py:115`, arithmetic mean). Claimed counterexamples exist (G=3 at subst_scale≈0.62+, G≥4 already indefinite at the shipped default subst_scale=0.6). Claimed shipped 17-country calibration is safe with a "3.3x margin" because RHO's own eigenvalue is small. Claimed fix: replace arithmetic-mean symmetrization with geometric mean (`np.sqrt(S*S.T)`), claimed to provably bound the spectral radius at exactly 0.95 always.
- **F2 [G, Low-med, 99%].** Claim: 8/17 shipped countries have M rows that are NOT diagonally dominant even though M is still PD in all 17 (safe by margin, not by the stated mechanism).
- **F3 [C/B, Medium, 98%].** Claim: an indefinite M produces a `DCPError` from cvxpy that is swallowed by a bare `except Exception: continue` at `core.py:281-287`, and execution falls through to `core.py:289` producing an opaque `TypeError` on `D.value=None`, not a diagnostic pointing at the real cause.
- **F4 [B, Medium, 99%].** Claim: b_g=0 (zero baseline consumption or elasticity) causes 0/0 in the rescale test and silently returns a NaN-poisoned M/Minv/a rather than raising.
- **F5-F13 [mostly H].** Claimed positive/confirmed: exact symmetry of M; correct integrability/gradient (∇W=p); correct consumer-surplus formula and one-grain limit; "Slutsky" label imprecise but integrability framing correct (G/D, low severity); intercept calibration D(p0)=D0 exact, a>0 in all 17 countries but thin margin; own-price elasticities exact, cross-price magnitude silently attenuated vs README's stated formula (H/G); dimensional consistency confirmed; strict concavity in D / uniqueness of (D,p) / non-uniqueness of f / lambda=p confirmed via dual extraction; sigma=0 decomposition confirmed to hold, EXCEPT the stress gate is claimed to be a single joint trigger across all grains (a real cross-grain coupling surviving sigma=0), with claimed zero observed consequence in the one scenario tested.
- **F14 [D/G, Low-med, 97%].** Claim: linear demand has only ~15% global supply headroom before the QP produces negative prices (no free disposal, no p>=0 constraint). Claimed this connects to extreme states other agents encountered.

## Agent 2 register — Strategic layer (`ExportRestrictionGame`)

- **F1 [H, 95-100%].** Claim: the coordinate best-response loop returns an EXACT Nash equilibrium of the discretized strategy grid (epsilon_i=0 exactly on the algorithm's own grid, tested across 204 runs incl. real in-run states).
- **F2 [H for tested calibrations, 95-100%].** Claim: coordinate-wise (not joint) optimization for multi-grain exporters (USA/Ukraine/Argentina restrict wheat+maize) produces a measured joint-vs-coordinate exploitability gap of exactly 0 in every scenario tested (welfare surface ~99.88% additively separable across a country's own grains).
- **F3 [C, Medium-high, 95-100%] — flagged as the single most important game-theory finding.** Claim: the default 5-point tax grid (spacing 30 $/t, tau_max=120) materially distorts BOTH margins: claimed the demo's own run reports ZERO restricting countries at t=6 (mid three-period shock) where a finer grid reports two restricting continuously; claimed the reported tau is up to 2x the fine-grid optimum where it IS reported. Claimed recommended fix: 2-stage local grid refinement inside the existing loop (~5 lines, ~2x cost) or minimally raising default game_grid from 5 to 13.
- **F4 [G, Low, 95-100%].** Claim: tol=3.0 is strictly smaller than grid spacing (30 or 20), so the convergence test is exactly "zero change", never a true epsilon-tolerance stop.
- **F5 [C, Low, 95-100%/80-95%].** Claim: max_iters=3 sufficed in 85/85 traced runs (no non-convergence, no cycling) but 48% of runs consumed the full 3-sweep budget, with no signal if it were ever insufficient.
- **F6 [H, 95-100% tested].** Claim: unique fixed point across 11 initializations x 8 player orderings on real stressed states, including the adversarial all-tau_max corner start.
- **F7 [H, 95-100% tested].** Claim: no cycling observed in 85 traced runs with explicit cycle detection.
- **F8 [H/G, 95-100%/80-95%].** Claim: stress gate verified non-binding when forced open in all 12 demo periods (calm periods return tau=0 exactly, not just approximately) — but claimed the gate's threshold (mu=1.12) sits ABOVE some countries' own p_target (Russia 265, Argentina 268) relative to the 280 threshold, an undocumented calibration-contingent safety margin.
- **F9 [D/G, Low-med, 95-100%].** Claim: producer income in `_welfare` uses UNSHOCKED baseline production `self.production0` (`core.py:440`), not realised Q*xi or post-storage sales. Claimed README-consistent (README's own notation defines Q as baseline) so NOT a coding bug. Claimed measured effect: zero at shipped grid=5, one 5$/t step at fine grid. **NOTE: this is the same code path Agent 3 flagged independently as S13 — the two Phase 1 agents disagreed only in confidence/completeness, not in the underlying fact.**
- **F10 [D/F, Medium, 95-100%].** Claim: in 9/20 tested multi-grain shortfall scenarios, essentially every exporter pins at the tau_max=120 upper bound simultaneously, making the equilibrium a statement about the arbitrary bound rather than about economics. Claimed the demo's own scenarios never reach this regime.
- **F11 [G, Low, 95-100%].** Claim: `tol` and `revenue_weight` are constructor arguments on `ExportRestrictionGame` but `SheafModel.__init__` (`core.py:387-388`) never forwards them, so revenue_weight (zeta) is unreachable via the only orchestrator and is silently 0 in every result the repo has produced.
- **F12 [H, 95-100%].** Claim: welfare function `_welfare` matches README §4 term-by-term with correct signs.
- **F13 [G, Low-med, 80-95%].** Claim: README attributes the "approximate equilibrium" caveat to welfare non-concavity (the food-security penalty kink), but claimed sampled welfare profiles are numerically concave/single-peaked — the real limitation is claimed to be grid discretization (F3), not non-concavity.

## Agent 3 register — Storage layer vs TWIST/Agrimate lineage

Sourcing note: Agent 3 claims access to primary Agrimate sources (Kuhla et al. 2025 paper + ODD supplement, local paths outside the repo) and a NON-primary local reconstruction of TWIST's mechanism (flagged as lower-confidence on TWIST-specific claims).

- **S1 [H, 99%].** Claim: country x grain x period material balance holds to solver precision (~1e-12) over a full 612-cell real run; no grain created or destroyed; the max(0,.) stock-recursion clip is provably inert given the shipped bounds.
- **S2 [H, 97%].** Claim: stocks provably cannot go negative; releases individually bounded; proved plus reproduced.
- **S3 [G, Medium, 95%].** Claim: README §3's storage formula matches the code symbol-for-symbol, but never states that p_ref is the PREVIOUS period's realised price (a load-bearing, unstated definition).
- **S4 [D primary /E/G secondary, HIGH severity, 95%] — flagged as the highest-value fix identified in the storage report.** Claim: `market_responsive_storage` receives NO production/shock argument (verified by signature), only p_prev — so private storage in period t is provably identical to evaluating the same rule at t-1's price, i.e. it responds to the ALREADY-KNOWN-BUT-UNUSED current harvest with a one-period lag. Claimed reproduction: Russia's wheat storage adjustment is EXACTLY 0.000 MMT in the shock period itself, with the buffer arriving one period later. Claimed both TWIST (simultaneous by construction) and Agrimate (uses current harvest, Eq D.6) are contemporaneous, so this is claimed to be a departure from the stated lineage, not merely a simplification. Claimed recommended fix: reuse the stress-gate probe price (already computed every period at `core.py:435-436`) as p_ref instead of p_prev — claimed zero new parameters/state, ~zero extra cost. **PHASE 2 NOTE: Agent 5 was tasked to independently compare this against 2 alternative timing architectures before endorsing it.**
- **S5 [D/G, Medium, 97%].** Claim: because the price expectation is a deterministic mean-reverting function of p_prev, the storage rule's true rest point is p* = kappa/(kappa+r) * p_norm, strictly BELOW p_norm for any r>0 (claimed 0.9091x at defaults) — and because calibration.py sets every country's p0=p_norm and initializes p_prev=p0, claimed the model is initialised EXACTLY on the release side, causing an endogenous downward drift in private stocks even with zero shock present. Claimed recommended fix: recentre p_norm so p*=mean(p0) (one-line, zero new parameters).
- **S6 [D, Low-med, 90%].** Claim: the symmetric +/-theta deadband is a transaction-cost band, not a Wright-Williams/Deaton-Laroque carrying cost (which would be one-sided); mkt_cost is claimed to be used ONLY as the band half-width and never charged in any welfare function; no spoilage/decay term exists anywhere in the module (grep-claimed).
- **S7 [D/G, HIGH severity, 97%] — flagged as a second top-priority storage fix.** Claim: the government "crisis" test (`Sigma = D0 - (Q*xi - Delta_mkt)`, no imports term) is an AUTARKY check, not a scarcity/anomaly check. Claim: for any structural net importer (D0>Q, e.g. China, Egypt in the shipped calibration), Sigma>0 identically REGARDLESS of any shock, so the rebuild branch is claimed structurally unreachable while gov_stock>0, and government reserves are claimed to be a one-way drain identical before/during/after the demo's shock (China maize 100->0.078 MMT, Egypt wheat 4.5->0.0011 MMT over 12 periods, claimed shock-independent). Claimed recommended fix: redefine the shortfall as an anomaly relative to baseline net-import position (Q*(1-xi)+Delta_mkt), zero-cost, zero new parameters. **PHASE 2 NOTE: Agent 5 was tasked to independently derive and compare shortfall definitions before endorsing this one.**
- **S8 [B, Low severity as shipped (claimed UNREACHABLE) / Medium for replaced calibrations, 95%].** Claim: `strategic_storage`'s crisis-release guard (`if crisis and gov_stock>0`) falls through to the BUILD branch when gov_stock==0 even during an active shortfall, because the build branch is only guarded by the price test, not by "not crisis" — a genuine mismatch with README's stated two-branch partition. Claimed proven unreachable in the shipped calibration (gov_release_frac=0.5 means stock decays asymptotically, never hits exactly 0 within realistic horizons) but reachable for a user-supplied calibration with target>0, stock=0.
- **S9 [E for the judgment /H for the underlying fact, Medium severity, 95%/75%].** Claim: storage decisions (core.py:423-431) are computed strictly BEFORE the stress gate and export-restriction game (core.py:434-443) each period, so mkt/gov storage changes are claimed BIT-IDENTICAL whether or not the game is played or what tau is chosen (reproduced: 0.0 exact diff even when the game moves prices by 29 $/t). Claimed this is a deliberate architecture choice (E), not an error, but claimed it gives SHEAF's storers LESS information than Agrimate's own lineage (where policy update precedes sales).
- **S10 [C, Medium-low, 95%].** Claim: negative effective availability (A = Q*xi - Delta_mkt - Delta_gov < 0) is reachable in principle (no production bound on the private build) but claimed NOT itself unphysical (a node can legitimately import to build stock) — refuting the agent's own initial hypothesis. Claimed the genuinely reachable failure is GLOBAL infeasibility (world availability for a grain going negative), which crashes with the SAME opaque TypeError at core.py:289 that Agent 1 found via a different trigger (indefinite M). Claimed unreachable in the shipped 12-period demo (min availability = 0.0000 exactly, n_neg_avail=0) but reachable in a constructed 2-period endogenous scenario. Claimed the two storage mechanisms do NOT jointly over-draw independently — government storage sees the private decision already (core.py:429 passes prod-dm in) and can partially offset via its crisis branch. **PHASE 2 NOTE: independently re-audited by Agent 4 (spatial equilibrium).**
- **S11 [C/D, Low severity (claimed latent, not reproduced as active), 90%].** Claim: `strategic_storage` has no capacity bound at all (no clip); `mkt_capacity` defaults to +inf if unset; claimed arithmetically safe in the shipped calibration by roughly an order of magnitude.
- **S12 [D, Low, 92%].** Claim: `mkt_cost` (the deadband width) is a single per-country SCALAR applied identically across grains despite grains having very different reference prices ($250/$400/$200), producing an unintended 2:1 variation in the effective RELATIVE deadband (3.2%/2.0%/4.0% of p0) across wheat/rice/maize. - **S14 [H, 98%].** Claim: expectations use strictly t-1 information only, no look-ahead; verified last_tau and p_norm cannot leak future information into the storage decision.
- **S15 [F, Medium, 85%].** Claim: storage parameters (R0, capacity, gamma, theta, release/build fractions, target ratios) are all hand-set illustrative placeholders, not sourced from data_usda.py's own stock-to-use computation despite that computation existing in the repo.
